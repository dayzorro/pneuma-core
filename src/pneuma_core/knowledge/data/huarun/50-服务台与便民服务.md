# 服务台与便民服务

## 服务台在哪里

服务台（顾客服务中心）通常设在门店主入口或收银出口附近，是顾客所有咨询与业务的统一入口：
到店有问题，先找服务台。

## 服务台能办理的业务

- 咨询引导：门店布局、商品在哪个区域、促销活动怎么参与、找哪个人
- 会员业务：办理会员卡、补卡、换卡、积分查询、积分兑换
- 退换货受理：核对商品与购物凭证，按门店规定办理退换货
- 预付卡/礼品卡：换卡、挂失登记、余额查询指引
- 发票：开具发票的指引与办理
- 失物招领：登记遗失物品、认领已上交的物品
- 广播服务：寻人、寻物广播
- 投诉与建议：登记顾客意见并转交相关部门，跟进处理结果

## 便民服务

- 免费开水、简易包扎、便民药箱
- 雨伞租借
- 充电宝借用
- 自助寄存柜（存放背包、购物袋等）
- 轮椅、婴儿车/童车租借
- 母婴室（一般配备婴儿床、饮水机等）
- 无障碍卫生间或无障坡道

## 服务台办不了的事（需要转交）

- 商品定价、促销规则的最终解释
- 超出门店公示范围的赔偿、补偿诉求
- 大额退款审批、员工服务投诉的处理结果

以上情况的正确做法：登记顾客信息与诉求，转交**当班值班经理**，或引导顾客拨打
全国客服中心热线 400-611-8866。

## 值班与交接

服务台按班次值守，早班与晚班交接时会核对便民物品（雨伞、充电宝、轮椅）数量与
失物登记本，确保顾客随时能借到、能查到。
